# Shapely

Shapely is a great Python library that helps us analyse and manipulate geometries. Shapely is an open-source package designed to bring the power of the Shapely Python library to Revit users. 
Shapely is a widely-used library for the manipulation and analysis of geometric objects, providing powerful functions for spatial analysis. With this package, Dynamo users can seamlessly work with Shapely’s geometry features directly within the Dynamo environment.

## Features

**Geometry Conversion** : Easily convert between Dynamo and Shapely geometry objects, ensuring data is preserved without loss during the transformation process.
**Advanced Operations** : Perform a variety of polygon operations, such as intersection, union, and difference, directly within Dynamo.
**Advanced Spatial Analysis** : Leverage Shapely’s built-in functions for more sophisticated spatial analysis tasks, like distance calculation, boundary analysis, and geometric relationships.

## Why Shapely for Dynamo?

While Dynamo is great for parametric design and automation, it lacks some of the advanced geometry manipulation tools available in Shapely. By integrating Shapely with Dynamo, you can perform complex geometry operations that are often needed in architectural and engineering workflows. This package bridges the gap between Dynamo and Shapely, providing an intuitive and powerful way to enhance your design processes.

## Installation

To install Shapely for Dynamo, simply download the package from the Dynamo Package Manager, or add it through the Dynamo Package search interface.
**Please make sure you have downloaded the latest version!**

## How to Use

Once installed, you can access Shapely functions directly within the Dynamo workspace. The package provides several nodes for manipulating and analyzing geometries. Check out the examples and documentation to get started quickly.

## Documentation

For detailed usage instructions, visit the **Shapely Docs** **https://shapely.mintlify.app/** to explore all available nodes, features, and examples.
